## How to attribute (if you fork or build on this)

The MIT license requires you to keep the copyright headers in source files when you redistribute. **It does not require visible attribution in your README or UI** — but if you'd like to credit, here's the convention:

### In a README

```markdown
Built on [design-system-starter](https://github.com/filotopist/design-system-starter) by [@filotopist](https://github.com/filotopist).
```

### In a video / tutorial / blog post

> "Based on the design-system-starter approach by Ivan Kolle (@filotopist)."

### In a derivative bundle / fork

Keep `CREDITS.md` intact or add your own author line above the existing one — don't replace it:

```markdown
## Author

**Your Name** — @yourhandle

This bundle is a fork of [design-system-starter](https://github.com/filotopist/design-system-starter) by Ivan Kolle.
```
